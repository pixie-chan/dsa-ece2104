Phase 04
Sorting & Searching
All major sorting algorithms, binary search mastery, and hashing. This phase teaches you to choose the right tool for the job.
Week 11 Sorting I: Basic + Merge Sort Lect 26–27
Learn
  • Bubble Sort: O(n²), swap adjacent. Stable.
  • Selection Sort: O(n²), find min, put at front. Not stable.
  • Insertion Sort: O(n²), build sorted prefix. Good for small data.
  • Merge Sort: O(n log n), divide-conquer-merge. THE most important sort.
  • Implement merge sort from scratch 3x until muscle memory
  • Master the merge step — it appears in counting inversions, etc.

Week 12 Sorting II: Heap Sort + Quick Sort Lect 28–29
Learn
  • Heap Sort: O(n log n), in-place, not stable
  • Quick Sort: O(n log n) avg, O(n²) worst. In-place, not stable.
  • Pivot selection: random, median-of-three
  • Partition: Lomuto vs Hoare
  • Quick Select: O(n) avg — find Kth without full sort
  • When to use which: space, stability, data distribution

Week 15 Dijkstra + Union-Find Lect 37–38
Learn
  • Dijkstra: O((V+E) log V) — shortest path, weighted, no negatives
  • Uses min-heap (priority queue), greedy expansion
  • Bellman-Ford: handles negative weights (O(VE))
  • Union-Find: union by rank + path compression
  • Used for: dynamic connectivity, Kruskal's MST
  • MST: Prim's and Kruskal's — know the concepts
