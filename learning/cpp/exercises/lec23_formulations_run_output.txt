=== 11. what the sheet is telling you ===
  only two of the eight structures carry padding: the nodes with a 4 byte payload next
  to an 8 byte pointer. Put the pointer first and the payload after it and the tail
  padding disappears, at the cost of reading the fields out of declaration order.
  the array based structures are exactly their payload plus one 8 byte index each:
  the stack is 32 + 8, the queue and the ring are 32 + 16. No pointers, no per element
  cost at run time, but a fixed capacity chosen before the first insert.
  the linked structures cost one 16 byte node (list) or one 24 byte node (tree)
  per element allocation, and the structure object itself is one pointer plus,
  optionally, one 8 byte counter.
  and the two index arrays (queue, circular queue) have the SAME sizeof: the count
  member in the circular version is the third index, and it is what makes full and
  empty distinguishable, so it is not optional there.
