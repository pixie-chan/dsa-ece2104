Lesson 01 / Linked List

A linked list is a freight train of boxes.

Every box (node) carries one value and a coupling (next) that holds the address of the next box. The train is one-way: you can only ride from head to NULL. This page is the control board, drive the train and watch the C++ do it.

One car, two pockets

A node is a tiny struct with exactly two pockets. The left pocket holds cargo (data). The right pocket holds an address (next): the address of the next box in the train. An empty right pocket means "this is the last car", and that is what nullptr is.

03

The vocabulary that sticks

Seven words carry the whole of linked lists. Each card gives you the plain meaning, then the hook that will still be in your head in exam season.

01 / head

The only door into the train.

Head is a pointer, not a car. It stores the address of the first car. Every single operation starts by asking head: "where is the front?"

head → 10 20 30 NULL
Hook: lose head, lose everything. The rest of the train may still exist in memory, but nobody knows where it is, so it is gone forever.
02 / node

A box with two pockets.

The struct. One pocket for your value, one for the address of the next box.

"A post-office box: parcel inside, forwarding address pinned to the door."
03 / next

The coupling.

The pointer inside each car that stores the address of the next car, or nullptr at the end.

"Every car only knows the car directly behind it. None of them know the station master's plan."
04 / NULL

The end-of-line bumper.

nullptr = "there is no next car". Every ride ends here. It is also how your loops know when to stop.

"NULL is the period at the end of the sentence."
05 / traversal

The ride.

Start at head, hop car to car via next, stop at NULL. That is 90% of linked list code.

"Hop until you can't hop anymore."
06 / pointer

A post-it with an address.

A variable that stores where something lives, not the thing itself. &x means "where does x live", *p means "go there".

"The post-it is not the house."
07 / O(1) vs O(n)

Front door, back door.

O(1) the front door is at the platform edge: jump on, done, takes the same time no matter how long the train is.

O(n) the back door: you must walk every single car to reach the last one. Longer train, longer walk.

"Front: one hop. Back: one hop per car."
08 / reference to pointer

Why Node*& (and not Node*)?

Because if you pass Node* head by value, the function gets a photocopy of the head pointer and any "head = n" inside is lost on return. Node*& head passes the pointer itself by reference: changes inside the function are changes to the real caller's head. The train's front door gets moved where it should.

"Photocopy vs the original. Push a car onto a photocopy and the real train never sees it."
04

The two derailments

Every beginner crashes here at least once. Press run on each broken console and watch the train derail, then read why the fixed version is safe.

TRAP Aself-loop

Wrong order turns a car into an ouroboros.

Correct order: fix the coupling first, then move head. Wrong order: move head first, then the car points at itself and the train rides in circles forever. A print loop never finds NULL, so it never stops.

head = n; then n->next = head;
Hook: coupling before crane. Point the arrow at the old head first, then lift the head flag onto the new car. Reverse it and the arrow curls back into itself.
TRAP Blost update

Head passed by value is a photocopy.

If the function signature is Node* head, assigning head inside only changes a local copy. The caller's head pointer stays nullptr forever, and the new car leaks, unreachable in memory.

head (caller)
→ nullptr copy (inside fn) → nullptr
Hook: "Push a car onto a photocopy, the real train never sees it." If a function must move the head, the parameter is the original: Node*&.

The whole engine, one listing

// LESSON 1: Linked List, a train of boxes
#include <iostream>
using namespace std;
 
struct Node {
    int data;        // the cargo
    Node* next;     // the coupling: address of the next car
    Node(int v) : data(v), next(nullptr) {}
};
 
void pushFront(Node*& head, int val) {
    Node* n = new Node(val); // build a new car
    n->next = head;              // coupling clicks onto the old head
    head = n;                    // head flag moves to the new car
}
 
void pushBack(Node*& head, int val) {
    Node* n = new Node(val);
    if (head == nullptr) { head = n; return; }
    Node* cur = head;
    while (cur->next != nullptr) cur = cur->next; // walk to the last car
    cur->next = n;               // attach after it
}
 
void popFront(Node*& head) {
    if (head == nullptr) return;
    Node* old = head;           // remember the front car
    head = head->next;           // head skips to the next car
    delete old;                 // free its memory
}
 
void printList(Node* head) {
    while (head != nullptr) { cout << head->data << " -> "; head = head->next; }
    cout << "NULL\n";
}
