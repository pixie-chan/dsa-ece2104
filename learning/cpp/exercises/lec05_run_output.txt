=== 5. padding: same fields, different order, different footprint ===
P1 {int a; char b; char c;}   sizeof=8  offsetof(a)=0 offsetof(b)=4 offsetof(c)=5
P2 {char a; int b; char c;}   sizeof=12  offsetof(a)=0 offsetof(b)=4 offsetof(c)=8
P3 {char a; char b; int c;}   sizeof=8  offsetof(a)=0 offsetof(b)=1 offsetof(c)=4
Node{int data; Node* next;}   sizeof=16  offsetof(data)=0 offsetof(next)=8  (4 bytes of padding so the pointer sits on an 8 byte boundary)

=== 7. cost is the shape: measured access time per element ===
  array walk  (arr[i], contiguous, hardware prefetcher helps): 0.19 ns/element
  array walk  (arr[idx], same array, scattered order):        2.46 ns/element
  linked walk (cur = cur->next, one dependent load per hop):  2.45 ns/element
  scattered array is 12.69x the sequential one and the list is 12.64x it, SAME O(n) work, different SHAPE
  (sanity: sums 15999992000000 and 15999992000000 agree? yes, scattered sum 15999992000000)

=== 8. the one line to remember ===
  address of element i in a contiguous block = base + i * sizeof(element)
  that single multiply is why indexed access is O(1);
  in a scattered structure you must follow links, so it is O(n).
